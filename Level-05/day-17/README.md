## 🧩 Problems Solved

* Check whether a number is a Strong Number.
Example:
145 = 1! + 4! + 5!
    = 1 + 24 + 120
    = 145

* Check whether a number ia an Automorphic number.
Example:
5² = 25
Last digit = 5
Therefore, 5 is Automorphic.

* Check whether a number is a Harshad Number.
Example:
18
1 + 8 = 9

18 % 9 = 0
Therefore, 18 is a Harshad Number.
